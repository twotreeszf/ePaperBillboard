# 长期接通 USB 是否安全

## 结论

**可以一直插着 5V 充电器使用。** 充满后充电芯片会自动停充，电芯不会被持续充电。电芯保护板是第二道保险。长期满电只会让电芯老化得稍快一些，不构成起火风险。

依据有三层：

1. **充电芯片自动停充**：电压到 4.2V 后转恒压，电流降到约 20mA 时切断充电。
2. **负载与电芯隔离**：插着 USB 时，整机由 5V 直接供电，Q1 把电芯和负载分开，停充判断不会被负载电流干扰。
3. **保护板兜底**：即使充电芯片失效，保护板也会在电芯过充时断开。

## 依据一：充电芯片自动停充

U4 是富满 **LTH7**，与 TP4054 同属单节锂电池线性充电芯片。以下参数来自它的数据手册。

| 参数 | 数值 | 依据 |
| --- | --- | --- |
| 充电电流 | 约 **210mA** | `I = 1000 / R_PROG`，R9 = **4.7kΩ** |
| 充满电压 | **4.2V ±1%**（4.16–4.24V） | 手册 V_FLOAT |
| 停充条件 | 电流降到设定值的 **1/10**（约 20mA） | 手册 C/10 终止 |
| 停充后电池漏电 | 约 **1µA** | 手册待机模式 I_BAT |
| 再次补电 | 电压回落约 **100mV**（约 4.1V） | 手册 ΔV_RECHRG |
| 过温降流 | 结温约 **120°C** | 手册 T_LIM |
| 输入上限 | 绝对最大 **7V** | 手册 V_CC |

充电分三段：电压低于 2.9V 时涓流（约 20mA），到 4.2V 前恒流（约 210mA），到 4.2V 后转为恒压，电流逐渐下降，直到停充。

**所以长期插着时，电芯停在 4.1–4.2V，只是偶尔补电，不会一直被灌电流。**

发热也有上限。线性充电的损耗为 `(5V − 电池电压) × 0.21A`，空电时约 0.4W，接近充满时约 0.2W。芯片过热会自动降低电流。

## 依据二：负载与电芯隔离

如果系统负载直接挂在电芯上，负载电流会混入充电电流，芯片可能一直等不到“电流降到 1/10”，也就迟迟不停充。这块板的电源路径避开了这个问题。

| 器件 | 接法 | 作用 |
| --- | --- | --- |
| R4、R5 | 5.1kΩ，分别下拉 CC1、CC2 | 声明自己是默认 USB 受电设备，合规充电器只输出 **5V** |
| D6 | SS34 肖特基，+5V → VCC | 插着 USB 时由 5V 给系统供电，VCC 约 4.5–4.7V |
| Q1 | SI2301 P-MOS，串在 BAT 与 VCC 之间，栅极接 +5V，R6 下拉 | USB 在位时**关断**，把电芯和负载分开；拔掉 USB 后导通，改由电池供电 |
| U10 | SPX3819，VCC → 3.3V，输入最高 16V | 给主控和墨水屏供电 |

**所以插着 USB 时，U4 的输出只流向电芯，停充判断准确。**

固件也依赖这个隔离来判断 USB 是否在位（`src/Tasks/TTSensorTask.h`）：

- `TT_BATTERY_ADC_PIN 33`：通过 R2、R3（各 100kΩ）分压测量 VCC。读数高于 `TT_BATTERY_USB_MV 4400` 时视为 USB 在位，因为单节锂电池本身达不到 4.4V。
- `TT_BATTERY_CHARGE_PIN 26`：接 U4 的 CHRG，低电平表示正在充电。状态栏据此显示闪电图标（充电中）或插头图标（已充满）。

## 依据三：保护板兜底

主板上没有单独的电池保护芯片，**电芯自带保护板**，在过充、过放或短路时断开电芯。

正常停充电压是 4.2V，低于保护板的过充切断点，所以日常使用时由 U4 控制充电，保护板不动作。只有 U4 失效，例如击穿后把 5V 直接送到电芯，保护板才会切断。

**所以即使充电芯片坏了，电芯也不会长期停在过充电压上。**

## 长期满电的代价

电芯长期保持在 4.1–4.2V，日历老化会加快，容量下降得比“用到一半再充”稍快。这是寿命问题，不是安全问题。

## 使用建议

- 使用 5V 输出的 USB 充电器。
- 放在室温、通风处，不要遮盖，也不要靠近热源。
- 0°C 以下不要充电。
- 电芯鼓包、破损或进水后，停用并更换。
